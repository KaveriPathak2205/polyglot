Polyglot

Real-Time Multilingual Voice Agent

Case 11 · Fresher Day Project

  • English · Hindi · Spanish
  • Local · Open-source · No paid APIs

Problem & Solution

The challenge

  • Assistants often lose context when language switches
  • Cloud voice APIs need internet and keys
  • Voice loops must feel instant (< 2 seconds)

Polyglot

  • Fully local Python CLI on a laptop
  • Mic → VAD → Whisper → Ollama → Piper → Speaker
  • Memory persists across EN → HI → ES turns

Architecture

  Microphone
      |
      v
  Silero VAD          (end of speech: 1.2s silence)
      |
      v
  faster-whisper      (text + language code)
      |
      v
  Ollama Llama 3.2 3B (reply + full history)
      |
      v
  Piper TTS           (voice matched to language)
      |
      v
  Speaker  ────────── loop

Key rule: Language updates each turn; conversation memory never resets.
