Polyglot

Real-time multilingual voice agent — English, Hindi, and Spanish — running fully on your machine.

View on GitHub How to run locally

The voice agent runs on your PC (mic + speakers). This site is the project showcase.

Architecture

Microphone

    v

    |
    v
faster-whisper      (transcript + language)
    |
    v
Ollama Llama 3.2 3B (reply + memory)
    |
    v
Piper TTS           (matched voice)
    |
    v

Run locally

The agent cannot run on Vercel — it needs your microphone, Ollama, and Piper on your laptop.

cd polyglot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
ollama pull llama3.2:3b
python main.py

See the repository README.md for Piper setup and evaluation scenarios.

Key features

  • Multilingual memory — context kept across EN / HI / ES switches
  • 100% local — no paid APIs, privacy-friendly
  • Language-aware replies — Whisper detects language; LLM follows
  • Per-turn latency — printed for evaluation
